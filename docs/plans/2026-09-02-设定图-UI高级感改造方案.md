## 先说改完会长什么样

打开《渡口》，中栏轨道是主角：白画布、场条、标尺。顶栏不再铺三排按钮。蓝色只点在「你正在看的这一场」。框只围着能输入、能选的地方。左栏一个搜索、一个新建。右边按「这场戏 → 钟 → 因果 → 账」折叠，不再把 `t=0` 和原始数据甩在脸上。

配色还是现在这套冷灰蓝壳 + 白画布，不是换成另一家的黑白风。做的是同一套颜色的成品化。

三句验收：

1. 打开书，眼睛先落到轨道上的场，而不是顶上那一墙按钮。
2. 同一屏里，只有「当前选中」在用那一抹蓝。
3. 66 条界面测试原文全绿，一个断言不放。

下面先写抄了谁、为什么难看、token 怎么落。文末才是给机器改的文件清单。

## 1. 对标抄了什么（网页实搜，不是凭记忆）

### 1.1 Aeon Timeline 3：克制，不是功能少

出处：

- 界面总览 <https://help.timeline.app/article/141-user-interface-overview>（2024-05-02）
- 时间轴页 <https://help.timeline.app/article/144-timeline-view>（2022-07-25）
- 检查器 <https://help.timeline.app/article/174-the-inspector>
- 入门 <https://www.aeontimeline.com/getting-started>
- 官方图已存 `/tmp/ui-shots/refs/aeon-ui-overview.png`、`aeon-timeline-view.png`、`aeon-inspector.png`、`aeon-toolbar.png`

打开官方图，一眼能数清六块：顶条看法、左侧图标条、实体名单、中间工作区、右侧检查器、底栏尺度。中间占了大半屏。顶条左边是看法图标，地方不够就收成图标、再收成一个下拉（官方原文）。尺度、分组、卡片细节不站在轨道上，站在**底栏**。当前正在用的那一屏，标题条用一抹亮蓝/青绿；没在用的那一屏把头褪掉。检查器上头是标题、类型、颜色；下面用页签/可折叠块，不是一长串平铺。

**抄这三条：**

1. 轨道区是主角。壳退后。
2. 控件按使用频率收：常驻图标组 → 下拉 → 面板。地方不够先藏字，再藏进菜单。
3. 强调色只标「正在看的这一屏 / 这一条」，不作全屏装饰。

**不抄：** 暗色默认壳、英文工具名、底栏英文图标密铺。我们亮色壳已经按 Aeon 采过色，这一单继续用。

### 1.2 Linear：少框、少抢戏、结构靠齐不靠线

出处：

- 2024 改版 <https://linear.app/now/how-we-redesigned-the-linear-ui>（2024-03-28）
- 2026-03-12 再收一刀 <https://linear.app/now/behind-the-latest-design-refresh>
- 品牌色 <https://linear.app/brand>
- 官方图 `/tmp/ui-shots/refs/linear-new-ui.png`、`linear-calmer-borders.png`

他们自己写的原则，对着我们现在的屏几乎是诊断书：

- 侧栏、页签、导航不该跟正文抢亮度。到了目的地，壳要再暗一档（2026 文：侧栏 dimmer，让主工作区领先）。
- 分割线会悄悄繁殖。新版把边修圆、对比度打淡，「结构要被感觉到，不要被看见」。
- 主题从 98 个色值收到 3 个源头：底色、强调色、对比度（LCH）。强调色稀缺。品牌蓝是低饱和，不是满屏刷。
- 正文在亮色里写得更黑，辅助字更灰，层级靠深浅，不靠每人一块描边。

品牌板：Mercury White `#F4F5F8`、Nordic Gray `#222326`，那抹蓝留给焦点，不拿去刷按钮墙。

**抄这三条：** 壳比画布退半步；框能删就删；强调色只给当前焦点。

### 1.3 Raycast：一个主角、三种控件语言、次要进底栏

出处：<https://www.raycast.com/blog/a-fresh-look-and-feel>（2022-07-19）

搜索条放大，因为它几乎是所有动作的入口。操作、提示、快捷键收进**窗口底栏**，不再跟结果抢。Compact 模式把其余元素淡掉。图标同一套描边、同一圆角、同一线宽。原则就三个词：快、简单、好用。

**抄这三条：** 一屏一个主角；按钮 / 输入 / 下拉三种长相必须能一眼分开；次要操作进底栏或 `?`，不要写成第三排字按钮。

### 1.4 Notion 的节奏（日历 + 页面）

出处：

- 页面改版 <https://www.notion.com/blog/updating-the-design-of-notion-pages>（间距先定尺子，再让邻居决定松紧）
- 日历设定 <https://www.notion.com/help/notion-calendar-settings>（左栏日历名单 + 中间格子是主角；密度用「放大/缩小时段」，不在格子上再铺一排按钮）

**抄这三条：** 间距用一把尺子（4 的倍数）；同类挨着就收紧，换组才留白；日历/轨道的密度调节放在「看法」里，不堆在格子上。

## 2. 设计系统选哪一套（落到我们自己的 CSS，不引库）

搜了三家通行做法，选定「角色抄 Radix、间距抄 Tailwind/Radix 4px、阴影抄 Material 3 精简成 2 级」。**不装** Radix / Tailwind / MUI。只把角色写成 `:root` 变量。

### 2.1 色：Radix 1–12 的职责，不是他们的色号

出处：<https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale>

| 阶 | 职责 | 我们怎么用 |
|---|---|---|
| 1 | 应用底 | 窗外那层浅灰 |
| 2 | 轻底 | 侧栏、顶栏 |
| 3 | 控件默认底 | 输入框底 |
| 4 | 悬停底 | 按钮/行 hover |
| 5 | 按下/选中底 | **只给当前选中的场条** |
| 6 | 弱分割 | 栏与栏之间，能省则省 |
| 7 | 可点控件描边 | **只有输入、下拉、按钮** |
| 8 | 悬停描边 / 焦点环 | 焦点环用品牌色，不是每个按钮悬停都刷蓝 |
| 9 | 实心强调 | **只有当前焦点**：选中场条边、页签底下那条、焦点环 |
| 10 | 实心悬停 | 主按钮按下 |
| 11 | 辅助字 | 钟、地点、提示 |
| 12 | 正文 | 场名、任务 |

现在的病：`--accent` 和 `--brass` 都是 `#6098D8`，页签填满、主按钮、开关、选中卡、hover、滚动条语义全吃这一口。Radix 明文：9 是最纯的一阶，滥用就会「全屏都在喊」。

### 2.2 间距：4px 一格

出处：

- Tailwind 默认间距 1 = `0.25rem` = 4px <https://v3.tailwindcss.com/docs/customizing-spacing>
- Radix Themes space 1–9 = 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64px <https://www.radix-ui.com/themes/docs/theme/spacing>

组件里禁止再写 `6px`、`10px` 这种不在尺子上的数（几何画布的 1px 线除外）。

### 2.3 字：只要三档

出处：Radix 字阶 12–60px <https://www.radix-ui.com/themes/docs/theme/typography>。我们只取三档，避免「每个按钮一个字号」。

- 标题 16px / 字重 600：书名、场名、弹窗标题
- 正文 14px / 400：任务、列表、按钮
- 辅助 12px / 400：钟、地点、快捷键提示

### 2.4 阴影：Material 3 的「少级、必要时才打」

出处：<https://m3.material.io/styles/elevation/applying-elevation>

Material 3 有 0 到 +5，静息只用到 +3，阴影只在「两块同色表面叠在一起、不打影就分不清」时用。重叠的场条就是这个情况。我们只留两级：贴着画布的轻影、叠在另一条上 / 弹窗的深影。

### 2.5 圆角两级

控件 6px，卡片和弹窗 10px。不再 4 / 6 / 8 / 10 混用。

## 3. 现在哪里难看（对照代码，不是印象）

现状图：`/tmp/ui-shots/10-timeline-zh.png`。代码基线 `apps/web/src/styles.css`（`border` 命中 **87** 处，与任务单一致）、`shell/Topbar.tsx`、`shell/LeftRail.tsx`、`scene/ScenePage.tsx`、`board/TimelineView.tsx`。

### ① 蓝色语义过载 — 属实

`:root` 里 `--accent` 与 `--brass` 都是 `#6098D8`；暗色把 `--brand` 也改成 `#70B0F0`。`--brand: #4665E1` 只写在变量里，**组件一次都没用**。

同一口蓝现在刷在：品牌字、主按钮、按钮 hover、按下态、页签当前项填满、选中场条、窗口「中」高亮、逻辑线开、齿条正史、焦点环、检查器色点默认。结果：打开书，到处都在亮，真正选中的「阿福发现刀在抽屉」并不比顶栏「打开书」更像焦点。

### ② 边框泛滥 — 属实

全局 `button { border: 1px solid var(--line) }`，所有按钮一出生就带框。顶栏按钮墙、窗口控件外框、展示块 `.sit-blocks`、书卡、场条、弹窗、chip，全是 1px 套 1px。Linear 2026 那张「少分割线」的前后对比，几乎就是我们的顶栏。

**规则：** 展示靠留白 + 浅底差 + 轻影。框只留给输入、下拉、以及真正的按钮（按钮用填充或透明，不要人人一个空框）。

### ③ 时间轴三排按钮墙 — 属实

`TimelineView.tsx` 的 `.view-header` 把这些平铺成同一字号：整卡、只留标记、卡行、地点、寿命条、依赖线、不分、按人、按地点、按逻辑线、按色、全收、全开、年、月、日、时、滑条、From、To、套上、拉远、拉近、全书、跳到某日、另存 PNG、草稿和正史、依赖跟着动、按依赖排好、左右、再加上一行操作提示。

Aeon 把尺度和分组放进底栏/面板。我们抄收纳，但有硬约束：**现有测试会直接点** `tl-group-person`、`tl-scale-slider`、`tl-from` / `tl-to` / `tl-from-to`、`tl-scale-day`、`tl-scale-hour`、`tl-life`、`tl-card-lines`、`tl-follow`、`tl-scale-book`、`tl-resolve-all`。这些必须仍在可见层（做成分段/图标组），不能塞进默认关上的菜单——关上 Playwright 就当看不见。

收纳方案：

- **常驻可见：** 分组（不分/按人/…）做成一段；尺度滑条 + 年/月/日/时；From–To；寿命、卡行、依赖跟着动、全书。
- **「视图」下拉：** 只留标记、地点勾选、另存 PNG、全收/全开。
- **「更多」或 `?`：** 操作提示那一行字（⌘滚轮…）离开轨道，放进 `?` 气泡。

### ④ 左栏乱 — 属实

`LeftRail.tsx` 一眼能数出的问题，和截图对得上：

- `人地道组规伏` 六个单字按钮，不看 title 不知道是什么。
- 「新建」出现两次：`rail-create` 和 `new-entity`。
- 下拉默认写「人物」，但选项里混着地点/道具/组织/规则/伏笔。
- 搜索框 + 「搜」按钮 + 「名字」输入，看起来像两个搜索。

CSS 里其实已经有 `.kind-dot` 六色，列表没用上。

改成一个实体面板：顶上一行搜索（保留 `ent-search` + `do-search`，测试要点「搜」）；下面一行新建（名字 + 类型下拉 + `new-entity`）；`rail-create` 改成展开「欲望/秘密」的 `+`，文案不再和第二颗「新建」撞车；列表每条带类型色点。类型单字条保留 testid，改成色点+完整字或只留 title，不能删。

### ⑤ 右栏漏开发者痕迹 — 属实

`ScenePage.tsx` 第 66–69 行：

- `sidebar` / `moment-col` / `moment-body` 三处都能画出 `t=0`
- `knows-list` 直接 `JSON.stringify(world.knows)`

截图右上角就是三行 `t=0` 加一整段原始对话 JSON，压在「本场规定情境」上头。条目色圆点、间隔分钟和「本场任务」同一字号同一权重平铺。

**不能真删节点：** `contract26` 要求 `sidebar` 可见；`ui-contract` 要求 `moment-col` / `moment-body` 文本里仍有 `t=`；点击脚本会读 `knows-list` 的 innerText。做法：给人看的界面不再展示这些；探针留在 DOM 里做成屏幕外/辅助类，**不要 `display:none` 掉 `sidebar`**。

给人看的右栏改成四块手风琴，默认只开「场页」：

1. **场页** 本场任务、动作/对白/内心、写入正史
2. **时间** 钟、锁定、寿命、间隔
3. **因果** 因为哪一场、读序、当众/私下
4. **账目** 世界账、人物账、读者账、伏笔（规定情境拆到这里，去掉外框）

条目色是修饰，降成辅助行，不跟「本场任务」抢。

### ⑥ 顶栏场名出现两次 — 属实

`Topbar.tsx` 第 50 行：`book-label` 旁边还有 `colLabel`（当前场的任务名）。第一行右侧又是 `intent` 输入框，默认正填着同一句「阿福发现刀在抽屉」。截图左右各一次。

书名本身也偏挤：下拉、输入、`book-label` 三处都能看到「渡口」。场名去重是这一单必做；书名三处里，测试认 `book-label` 和 `book-list`，输入框留给「创建书」，可见文案只让 `book-label` 承担「现在打开的是哪本」。

### ⑦ 重叠场条像画错 — 属实

`packRows` 已经把时间重叠的场分到不同行（阿莲在上、阿禾在下），所以不是没排。难看是因为两条贴在一起、影几乎看不见（`.tl-bar` 只有 `0 1px 2px`），选中那条的蓝框和下面那条的顶边粘成一块黑。

改法：行距加一档；非首行或时间重叠的条用第二级阴影；选中条再抬一档，左缘略错 4px。不改 `packRows` 的排序语义。

### 额外四块（任务单点名，代码确认）

**书架** `ShelfPage.tsx`：书卡家家 1px 框，主按钮和次按钮一个长相，「打开」写了两遍（卡上一次、菜单里一次）。改成浅底 + 轻影，主行动一个实心「打开」。

**分场条** `Stripboard.tsx`：列与列 `border-right`，卡 `border: 1px solid var(--brass)`（连没选中的卡也在用强调色描边）。选中才允许强调色；列与列改用底差或极淡分割。

**弹窗** `Dialogs.tsx`：原生框 + 1px 线，按钮墙。改成第二级阴影、无重框、主/次按钮分色。testid 全留。

**命令面板** `CommandPalette.tsx`：已经是「一个搜索主角」，最接近 Raycast。主要是去掉按钮描边、分组用留白，不要再套一层框。

**暗色** 必须同步改变量，不能只改亮色。暗色里 `--brand` 今天被改成浅蓝，这一单改回来：品牌色在两套主题里都只当焦点。

## 4. 各屏改完你打开会看见什么

### 书架

浅灰底，书卡白底轻影，没有一圈灰线。书名 16px，主脑 14px，进度 12px。只有一颗实心「打开」。空书架仍是「还没有书。从这里开始写第一本」。

### 顶栏

一行：左「设定图」+ 暗色 + 书名；中「写下一场」（唯一实心主按钮）+ 本场任务输入；右「书架 / 书页 / 书的设定」做成轻文字，窗口疏中密收成一组分段，不再每人一个空框。「看法」「更多」「只看某人」进第二行或「更多」。逻辑线齿条仍在，但做成浅底胶囊，选中才描边。场名只出现在本场任务输入里一次。

### 左栏

比画布略暗一档（Linear 那句「壳退半步」）。一行搜索，一行新建，下面名单带色点。没有第二颗大「新建」。

### 时间轴

页签栏仍是冷灰蓝壳，**当前页签改成白底坐在壳上**，不要整颗填蓝。轨道白画布。工具条从「三排字」收成：左分组、中尺度、右视图/`?`。提示行从轨道上消失。场条默认淡灰边 + 轻影；选中才用品牌色描边和浅填。重叠的两条能看出上下。

### 分场条

和时间为同一本书的另一种看法。列头、卡、选中规则跟时间轴同一套 token。不再「每张卡都铜蓝描边」。

### 检查器

打开一场，先看见这场要干什么、动作对白内心、写入正史。钟、色、间隔在「时间」里，点开才占地方。右上角不再出现 `t=0` 和 JSON。

### 命令面板 / 弹窗

一个搜索、分组留白、无框列表。弹窗浮在第二级阴影上，主按钮实心，取消是文字按钮。

## 5. Token 表（全部 `:root`，组件禁止魔法值）

亮色默认（Aeon 壳基调保留）。暗色在 `html[data-theme="dark"]` 覆写同一组名字。

### 5.1 色

| 变量 | 亮色 | 暗色 | 只用在 |
|---|---|---|---|
| `--bg-app` | `#F4F6F8` | `#2A2E34` | 窗外 |
| `--bg-chrome` | `#BDD5EF` | `#3A4048` | 页签栏壳，不再当按钮色 |
| `--bg-chrome-2` | `#D8E0F0` | `#32363C` | 看法条底 |
| `--bg-canvas` | `#FFFFFF` | `#2A2E34` | 轨道、正文 |
| `--bg-panel` | `#F7F8FA` | `#32363C` | 左右栏（比画布退半步） |
| `--bg-subtle` | `#EEF1F4` | `#3A4048` | 展示块浅底，替代描边 |
| `--bg-hover` | `#E8ECF1` | `#42484F` | 行/按钮悬停 |
| `--bg-selected` | `#E8EEFC` | `#1E2A4A` | **仅当前选中场条/行** |
| `--text` | `#1C2024` | `#E8EAED` | 正文 |

### 5.5 三种控件语言（必须能一眼分开）

1. **按钮** 无框。次要：透明底 + 正文色；悬停浅底。主要：`--ink` 实心。按下/选中：浅底或下划，**不要描蓝框**。
2. **输入** 浅底 + `--line-strong` 一圈。焦点才品牌环。
3. **下拉** 与输入同高、同圆角；打开的菜单用 `--shadow-2`，菜单项无框。

展示块（规定情境、辅助说明）无框，只用 `--bg-subtle` 和上下留白。
