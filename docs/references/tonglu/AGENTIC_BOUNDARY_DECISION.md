## 现行决策：乙（对话驱动写 · 审批落库）

### 作者面

- **正典上只做**：与主编讨论 · 批准/拒绝写入提案 · 接受/弃用正文提案。
- **正典上不做**：设定/北极星/大纲/节拍/演绎/伏笔等**业务表单直填**。
- 凡 UI 仍暴露业务表单直写 = **缺陷**，须改为「让主编处理」+ WriteProposal 审批。
- **素材例外**：素材是作者的非正典参考记忆，作者可直接新建、编辑、置顶、归档和删除；这些动作不是世界状态写入。

### 写入通道

- 主编经 MCP / Hermes Run 使用正典写工具；**一律** `commit_if_approved`（或等价审批）。
- 主编对素材仅保留只读搜索、召回和引用；不提供素材 CRUD 工具。`s3_delete_codex` 不得归档/删除 material。素材要转为事实时走 `s3_promote_material`（待批，不改素材行）。
- 支持**批量 WriteProposal**（一次批准多条 op）。
- 单一落库点：`_execute_write` / store 写门控不变。

### 只读

- 设定库、卡片墙、看板、图谱、时间线：默认**只读检视** + 跳转对话 CTA。
- agentic 联查工具保持只读 hint。
- `s3_material_recall` 保持只读 hint，召回结果只能作为“参考/借鉴”，不能当成正典事实。

### 后门（非作者主路径）

- 正典 REST 直写可保留给自动化测试与「紧急直写模式」（默认关闭，须显式开启并打审计日志）。
- `/materials` 与 `/objects/material` 不属于该后门，而是作者素材工作台的正常 API；硬删仍必须遵守影响检查与 `confirm_impact_token`。
- **不得**作为产品文档或验收中的正常步骤。
