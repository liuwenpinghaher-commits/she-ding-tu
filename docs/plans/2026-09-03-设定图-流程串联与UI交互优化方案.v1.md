# 设定图：从空白书写出五场——流程串联与 UI 交互优化

**状态：只出方案，不改代码。** Hermes 审过后再派开发单。基线 `d80592b`（`apps/web`）。

**真源：** [`docs/设定图-v1.md`](../设定图-v1.md) 九条与三个操作；[`2026-09-01-设定图-Aeon交互与界面照抄方案.md`](./2026-09-01-设定图-Aeon交互与界面照抄方案.md) 已落地的第一～四刀；[`2026-09-02-设定图-UI高级感改造方案.md`](./2026-09-02-设定图-UI高级感改造方案.md) 病灶 7 条（部分 token/收纳已落地，主线流程未按作者走完）。

**NN：** NarrativeNode。本机 `vendor/` 无 NN 源码树。对照认 [`docs/references/narrative-node.md`](../references/narrative-node.md) 与 `demos/nn-mock-渡口.md` / `demos/stripboard-v1.html`。许可证 source-available，**禁止把代码复用进产品**。借「一场一块、在场标记、画布手感」，不借「按人物一条线」。

## 0. 三句话

1. **现在能测通，人走不通。** 主线控件大量藏在 10px 透明 `qa-hook` 里；新书默认页签只有时间轴，分场条要自己 `+` 再开；`写下一场` 之后测试还得手动切分场条再点草稿卡（`e2e/playwright/helpers.ts` 的 `selectDraftCard`）。
2. **写戏面是 NN 的一场一块，看钟面是 Aeon 的时间轴。** 两面同钟、同场。九条第 4 条「默认分场条」被 Aeon 默认时间轴盖掉了——要共存，不是再选一次边。
3. **先把空白书→第五场走顺，再收高级感。** 蓝色过载、框多、工具条墙是真病灶，但作者卡死在「本场任务打在哪、人怎么拖上场、模型填完去哪看」。

```mermaid
flowchart LR
  blank[空白书]
  ent[建人/地/物]
  task[写本场任务]
  next[点写下一场]
  chip[拖在场标记]
  fill[人改或模型填框]
  box[写入此框]
  canon[写入正史]
  blank --> ent --> task --> next --> chip --> fill --> box --> canon
  canon --> task
```

## 1. 基线：打开现在长什么样

代码对照均给 `apps/web/src/` 路径。测试钩子类名 `qa-hook`：`styles.css:248-270` 做成 10×10、透明、字号 0，人看不见，Playwright `getByTestId` 仍点得到。

### 1.1 整窗

```
┌──────────────────────────────────────────────────────────────────┐
│ [qa-tray 透明钩子叠在左上] 设定图  主题  选书▾  书▾               │
│ ‹ ›  − n/total +  疏中密     [写下一场]   ⋯操作▾   逻辑线胶囊     │
│ 页签：时间轴 ×   +   分屏                                         │
├────┬─────────────────────────────────────────────┬───────────────┤
│类型│ 中栏：时间轴（默认）                         │ 检查器        │
│搜  │  视图▾ 里才有分组/尺度/依赖                   │  场页手风琴   │
│新建│  轨道 + 场条                                 │  写入正史     │
└────┴─────────────────────────────────────────────┴───────────────┘
```

- 新书默认页签 **只有时间轴**：`shell/workspaceTabs.ts:88-90` `defaultTabInstances` 返回 `[{ id: "时间轴", kind: "时间轴" }]`，`DEFAULT_TAB = "时间轴"`（L29）。分场条不在第一屏。
- 顶栏人能看见的：品牌、主题、`book-list`、书菜单、窗口疏中密、**写下一场**、⋯操作、逻辑线齿。`shell/Topbar.tsx:79-189`。
- 顶栏人看不见、测试在点的：`book-name` / `create-book` / `intent` / `place-id` / `add-column` / `look-occupancy` 等，全在 `Topbar.tsx:42-78` 的 `.qa-tray`。
- 左栏人能看见：类型色点、搜索、名字+类型+新建、名单。`shell/LeftRail.tsx:53-124`。`do-search` / `rail-create` 仍是透明钩子（L42-51）。
- 右栏：场页手风琴已开；`sidebar` / `moment-*` / `knows-list` 已做成 `.probe`（`scene/ScenePage.tsx:70-73`），人眼不再被 `t=0` JSON 砸——高级感 ⑤ 这一条已落地。规定情境六块仍平铺在场页里（L77-84），和「本场任务」输入框再写一遍。

### 1.2 写下一场实际做什么

`state/store.tsx:692-709`：读隐藏的 `[data-testid=intent]`（没有则用 store），POST `/api/write-next`，再 `/api/select` 选中新草稿。**不切页签到分场条。** 若当前是出场/进度等 EXTRA_LOOK，会把 hash 拨回上次工作区页签，仍多半是时间轴。

测试侧自己承认这条缝：`e2e/playwright/helpers.ts:38-45` 注释「点开刚写下的草稿卡，右边栏才能填。拖人不代替点选。」实现是 `openStripboard` + 点 `.card.draft`。

### 1.3 模型填场

UI 只有 `fill-fake`（`ScenePage.tsx:131` → `/api/fill-fake`）。API 另有 `/api/fill-live`（`vendor/narra/src/bin/setting_api.rs:819`），前端没按钮。填完结果进讨论稿，须再点「写入此框」或「用动作/用对白/用内心」才进格子（`store.tsx:1069-1096`）。符合九条第 2 条，但作者在时间轴上看不见这条链路。

### 1.4 没有的入口（分支会踩到）

- **删草稿**：`/api/delete-draft` 存在，前端无按钮。测试用 `page.evaluate(fetch)`（`ferry.plays.spec.ts:82-90`）。
- **真模型填场**：无 `fill-live` 按钮。
- **中间 ➕ 插列**：顶栏 `add-column` 是透明钩子；人眼在「⋯操作」里有「加列」。分场条列缝是否有 ➕ 以 `Stripboard.tsx` 列头为准，不是顶栏 `+`（顶栏 `+` 是本页多显示一列，`Topbar.tsx:127`）。

## 2. 业务主线：空白书写出《渡口》前五场

素材认 `scripts/rebuild_ferry.py` 的前五场正史（主脑「渡口夜里，铜牌三日，刀在抽屉。」）。走查以**真人点界面**为准，不走重建脚本。每步：操作 → 系统反馈 → 当前控件（文件:行）→ 问题（分级）。

分级：**卡死主线** / **别扭** / **瑕疵**。

### S3 · 写下本场任务（第一场）

第一场要写：「阿福发现刀在抽屉」。地点：渡口。

| | |
|---|---|
| 作者会找 | 顶栏「写下一场」旁边的任务框。 |
| 实际 | 顶栏 `intent` / `place-id` 是透明钩子（`Topbar.tsx:50-51`）。人眼任务框在**右栏场页** `ScenePage.tsx:97`，且 **没有 `data-testid=intent`**。 |
| 写下一场按钮 | `write-next` L135-142：`disabled={!s.intent.trim()}`，title「没有本场任务不准写下一场」。 |
| 问题 | **卡死主线：** 主按钮在顶栏，任务打在右栏，空书右栏像闲置说明书（规定情境六块全是「还没有」）。作者点「写下一场」一直灰。不知道要先在检查器里打字，更不知道检查器那一格和隐藏钩子是同一份 `s.intent`。 |
| | **别扭：** 地点同样藏着。不填地点也能 POST（`place_id` optional），第一场地点空，后面穿帮检查吃亏。 |

**线框（现状）**

```
顶栏:  [写下一场 灰]  ⋯操作
右栏:  本场任务 [        ]   ← 人要跑到这儿打字
       本场地点 [        ]
       规定情境：还没有 ×6
```

**线框（本方案要改成）**

```
顶栏:  本场任务 [阿福发现刀在抽屉        ]  地点 [渡口 ▾]  [写下一场 实心]
       没任务时按钮灰，title 仍是「没有本场任务不准写下一场」
```

### S4 · 点「写下一场」

| | |
|---|---|
| 操作 | 任务有字后点 `write-next`。 |
| 反馈 | 新建草稿，API 选中它。时间轴上多一条短条（`card-{id}`）。**页签仍是时间轴。** 分场条若没开过，中栏没有一行一场的卡，也没有芯片可拖。 |
| 问题 | **卡死主线：** 写戏容器（分场条卡 + 在场芯片）不在当前页。时间轴条能点开检查器，但拖人上场的合同写在分场条卡 `onDrop`（`Stripboard.tsx:230-234`）。时间轴条是否接 drop：`TimelineView.tsx` 场条无对等 `onDrop`。人在默认主面拖「阿福」到条上，没有在场。 |
| | 测试用 `selectDraftCard` 绕开——产品不能把「切页签再点卡」当作者合同。 |

### S5 · 把人拖上场（在场标记）

| | |
|---|---|
| 正确操作 | 先开分场条（页签 `+` → 再开分场条，`TabBar.tsx:121-136` `tab-add-分场条`）→ 点草稿卡 → 从左栏 `ent-阿福` 拖到 `.card.draft`。刀作为道具同样拖。 |
| 反馈 | 卡上出现 `chip-阿福`（`Stripboard.tsx:282-305`）。点芯片打开档案并 `setSelectedChip`。芯片可拖回左栏拿掉在场。 |
| 问题 | **卡死主线：** 分场条不在默认页签；`+` 的文案是「再开分场条」，不像「去写戏」。 |
| | **别扭：** 拖人不自动选中该卡（helpers 原话）。先拖后点，右栏填的可能还是上一场。 |
| | **NN 缺口：** 芯片只有名字，变更不挂在标记下。刀「holder=阿福」要跑到场页「本场变化」手填 `delta-ent/attr/val`（`ScenePage.tsx:459-486`），不像 NN 的 change-subchip。 |

### S6 · 填动作 / 对白 / 内心，或让模型先填

| | |
|---|---|
| 人填 | 右栏 `do-text` / `say-text` / `think-text`（`ScenePage.tsx:109-111`）。800ms 级存草稿，`save-dot` 显示已存。 |
| 模型 | 点「假模型填场」→ 讨论稿出现三行 → 「用动作」或「写入此框」。讨论稿标明「讨论不是历史」。 |
| 问题 | **别扭：** 按钮写「假模型」，作者会以为产品坏了。真填 `/api/fill-live` 没入口。 |
| | **别扭：** 填完人不知结果在讨论稿里。时间轴上看不见讨论面板。 |
| | **瑕疵：** 规定情境六块与本场任务输入重复；「建议本场对伏笔做哪一件」空场也占一行。 |

第一场建议人写（对齐重建脚本）：

- 动作：阿福拉开柜台抽屉，油布里躺着一把短刀。
- 内心：阿莲今晚来找铜牌。抽屉不能开给她看。
- 价值转折：无知→把柄
- 本场变化：刀.holder = 阿福
- 知情：阿福 知道 刀在抽屉；可见范围仅阿福

### S8 · 第二场「阿莲来找东西」（吃全部历史）

重复 S3–S7。任务：阿莲来找东西。地点仍是渡口。在场：阿莲、阿福。

| | |
|---|---|
| 规定情境应出现 | 上场转折「无知→把柄」；世界账里刀在阿福手里；人物账：阿莲不知刀、阿福知道。这是九条第 5 条：本场任务用全世界，嘴巴用各人知道的。 |
| 问题 | **别扭：** 六块在场页顶上，和正在填的动作区抢。作者写对白时看不见「阿莲不该想起抽屉里的刀」。NN 的做法是点在场标记立刻看到此人此刻知情——我们点芯片开的是**档案**（`Stripboard.tsx:294-295` `openDossier`），不是这一刻的「他知道什么」。 |
| | **卡死（知情差）：** `know-block` 在场页很下面（`ScenePage.tsx:518+`）。第二场要写阿福撒谎、阿莲信错铜牌在柜面，入口不像在场标记的一部分。 |

### S9 · 第三场并列「阿禾在城里等信」

| | |
|---|---|
| 正确操作 | 选中第二场那一列 → 「在本列再写一场」（⋯操作，或钩子 `add-parallel` `Topbar.tsx:52` / `writeParallel` `store.tsx:711-732`）→ 地点改城里 → 拖阿禾上场。故事时与阿莲那场重叠、人不撞。 |
| 问题 | **卡死主线：** 「在本列再写一场」不在写下一场旁边，藏在 ⋯。作者会再点「写下一场」，得到**下一列**，变成顺序场而不是同时场。时间轴上重叠条靠 `packRows` 分行（高级感 ⑦），看不出「同列同时」。分场条同列号的卡视觉成一组才是 v1 合同。 |
| | **别扭：** 并列需要先选中「哪一列」。空点轨道没有列选高亮。 |

### S10 · 第四场省略「阿莲连夜赶回城里」

| | |
|---|---|
| 操作 | 写任务「阿莲连夜赶回城里」→ 写下一场 → ⋯操作「省略场」（钩子 `ellipsis` `Topbar.tsx:70`）。省略场不填动作/对白/内心，必须有任务，可带换地变化。 |
| 问题 | **别扭：** 省略场入口藏 ⋯，且是「先有草稿再改成省略」，不是创建时勾选。卡样式 `.ellipsis` 有，空态没说「这是赶路，不用演」。 |

### S11 · 第五场「阿福把刀藏进帮里仓」

回到渡口、阿福、刀。吃第四场之前的全部正史（刀仍在抽屉侧的把柄，阿莲已离开）。

| | |
|---|---|
| 问题 | **瑕疵：** 时间轴默认尺度对「一夜」可能一条太窄或太宽，尺度滑条常驻（`tl-scale-slider` 可见），年/月/日/时在「视图▾」里。写五场短夜戏够用，但「视图」里仍是一长串，高级感 ③ 未按「常驻分组+尺度、其余进菜单」收完——可见层把几乎全部项塞进一个 details，等于第二堵墙。 |

### S12 · 主线走完后作者心里应有的账

世界上为真：刀在帮里仓（阿福知道）；阿莲在城里（信错过铜牌在柜面）；阿禾在城里干等；伏笔「铜牌三日」未收。读者见过刀，阿莲没见过——读者账。

若五场都只在时间轴上用检查器硬填、从不打开分场条，**在场芯片、同列同时、省略场样式**全部缺席。这就是「UI 还是不行」的主因：Aeon 壳在，NN 写戏面不在第一路径。

## 3. 分支流程

### B1 · 改时间：拖列侵入 → 整列重规划 → 确认变更

| | |
|---|---|

## 5. NN 交互对标

对照 [`narrative-node.md`](../references/narrative-node.md)。禁止复制 `SceneNode.jsx` / `narrativeChain.js` 或任何 NN 源码。

| NN 模式 | 解决上面哪条 | 设定图该长什么样 |
|---|---|---|
| **一场一块**（场景是容器，不是人物横轴上的点） | P2 P3：写戏要有块可点可丢 | 分场条一行一块；块=草稿或正史。时间轴条是同一场的钟向投影，不是第二套场。 |
| **在场做成标记**（人/地/物贴在块上） | P4 P8 P13 | 块上芯片行：已在场芯片 + 末尾 `+`。拖左栏实体到块=加在场。拖回左栏=拿掉。时间轴「只留标记」模式应显示**同一组芯片**，不是另造泳道。 |
| **变更挂在标记下** | P8 知情差、本场变化难找 | 选中芯片：浮层/检查器切到「这个实体在这一场」——情状差、他知道什么、本场变化里与他有关的行。不替换左栏设定名单。 |
| **本场按来源分组** | 规定情境六块与填写区抢 | 点块：按来源看这一场（在场 / 变化 / 知情）。点列：这一刻清单。改内容仍回这一块，不开第二份编辑器。 |
| **画布手感**（块可点、标记可拖、悬停工具不挡） | P5 插场、B2 | 分场条：列缝悬停 ➕。时间轴：已有条上工具（复制/在上建/在下建/锁定，`data-flip`）。不要十三档画布坐标参与故事序。 |
| **出场矩阵飞出** | 看谁在哪几场 | 已拍板：标尺色点 + 点列；飞出层只读。不作默认主面。 |
| **不借：每人一条链、一改即历史** | — | 算出这一刻仍叠全部已正史场。点写入正史才进历史。 |

**画布手感三条可验收（不引 NN 组件）：**

1. 块是 drop 靶，空卡也像容器（虚线「拖人上场或点 +」）。
2. 标记可拖、可点；点标记 ≠ 点块（现在芯片 `stopPropagation` 已对，但点了开档案，应改为打开「这一场的这个人」）。
3. 悬停工具不改变块的故事时间；工具翻上/翻下已有（`placeHoverTools`）。

## 6. 为什么 Aeon 照抄 + NN 手感可以共存

不是再投一次票「主面到底是时间轴还是分场条」。

| 面 | 学谁 | 干什么 | 九条 |
|---|---|---|---|
| **时间轴** | Aeon | 按分钟看这场持续多久、重叠、依赖、缩放 | 第 4 条「按故事时排戏」的**看钟**；不是实体泳道 |
| **分场条** | NN 一场一块 | 写厚：任务、在场、动作/对白/内心、写入正史 | 第 4 条「默认是分场条」的**写戏** |
| **检查器** | Aeon 手风琴 + NN 点标记看这一刻 | 选块=场页；选芯片=该实体在这场 | 第 2 条写入此框；知情侧栏 |

**同钟同场：** 两条页签改的是同一场、同一份 Narra，逻辑线/讲述序仍不算 fold（Aeon 方案第 1 节「只留会改故事真假的边界」不动）。

**默认怎么开：**

- 新书页签 **两枚都开**：时间轴 + 分场条。当前枚：**分场条**（守九条第 4 条空态「一行一场」）。时间轴还在，一眼能切。
- 点「写下一场」：若当前不是分场条，切到分场条并选中新草稿（P3）。时间轴条同步出现。
- 分屏保留：时间轴 | 分场条。允许把时间轴收到很窄，**不允许把分场条从「写下一场」路径拿掉**（可关页签，但写下一场会再打开）。
- 分组「按人」是时间轴看法，**不是**默认主面，避免滑回 NN 的人物链。

这样 Aeon 的壳（三栏、页签、尺度、即时拖钟+⌘Z）和 NN 的块（容器、标记、挂差）叠在同一产品上，不破九条。

```
┌─────────────────────────────────────────────────────────────┐
│ 设定图  渡口▾     本场任务 [              ] 地点 [渡口▾]     │
│                   [写下一场]     本列再写一场    ⌘K         │
│ 页签：分场条 · 时间轴 · 总表 · …                             │
├────┬────────────────────────────────────────┬───────────────┤
│ 人 │  一行一块（NN）                         │ 场页 / 这一刻 │
│ 地 │  ┌阿福发现刀在抽屉─────────┐            │ 芯片选中时：  │
│ 物 │  │ [阿福] [刀]              │            │  他知道什么  │
│搜+ │  │ 无知→把柄                │            │  本场变化    │
│    │  └─────────────────────────┘            │ [写入正史]钉底│
└────┴────────────────────────────────────────┴───────────────┘
切时间轴：同一场变成按时长的条，芯片仍在条上（只留标记）。
```
