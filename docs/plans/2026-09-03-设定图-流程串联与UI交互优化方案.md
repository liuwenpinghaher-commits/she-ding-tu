## 0. 一句话

产品现在是 **Playwright 的快速引导**（透明 10px 钩子 + helpers 替你切页签点卡），不是作者的快速引导。把同一条路径做成可见的 coach marks，会立刻暴露：一半功能在 `⋯操作` 或钩子里，反馈在右栏折叠里，术语在规定情境里成立、在人眼里不成立。

## 2. 快速使用引导脚本（交付主体）

假定产品有新手引导（tour / coach marks）。给**完全没见过的作者**。每步回答四句：**我在哪 / 刚才发生了什么 / 下一步做什么 / 做砸怎么退**。

判定是对照 **现在的真实 UI**（8787《渡口》截图 + 代码），不是对照理想稿。

档：✅ 顺畅 · ⚠️ 别扭 · ❌ 走不通。

气泡用人话。括号里是现界面字，引导不要照念术语。

### 2.1 主线 G：从空书到「3 场正史 + 1 次回退 + 1 次导出」

用一本新书「试写」，三场借用《渡口》骨架，免得引导和示例书打架。

#### G0 · 门厅认路

| 字段 | 内容 |
|---|---|
| 停留 | 书架（`#/`，`shelf`） |
| 气泡 | 「这是你的书单。打开一本继续写，或新建一本。」 |
| 用户做 | 看清《渡口》和「新建书」。本引导点 **新建书**（避免在示例书上练习删改）。 |
| 预期 | 进入新建书页。 |
| 分支 | 点开《渡口》→ 跳 G2'（示例书观光，见 2.2）。点测试垃圾书 → 气泡「这是开发留下的书，先忽略。」 |
| 现状 | ⚠️ 顶栏「写下一场」在书架就出现且是灰的（[01-shelf](./assets/guide-audit/01-shelf.png)）。书架被 f40-* 测试书淹没，《渡口》不易当第一本。删书藏在卡 ⋯。 |

#### G1 · 建一本只要两格的书

| 字段 | 内容 |
|---|---|
| 停留 | 新建书（`new-book-page`） |
| 气泡 | 「先起个书名。下面『起点对应分钟』可以先不管。」 |
| 用户做 | 书名填「试写」，主脑可空，点「建这本书」。 |
| 预期 | 进工作区，书名在顶栏。 |
| 分支 | 书名空 → 按钮应继续灰并说「先起名」（现：`nb-create` 可点后报错，见 NewBookPage）。取消 → 回书架。 |
| 现状 | ⚠️ [16-new-book](./assets/guide-audit/16-new-book.png) 一次甩出「起点对应分钟 / 一格多少分钟 / 显示格式」。新手引导必须把后三格标成「以后在书的设定里改」。顶栏仍停在上一本「渡口」。 |

#### G2 · 告诉你现在在哪

| 字段 | 内容 |
|---|---|
| 停留 | 工作区中栏 |
| 气泡 | 「中间是这场戏的桌子。左边是人/地，右边是这场的细账。上面『写下一场』是唯一主按钮。」 |
| 用户做 | 只看，点「下一步」。 |
| 预期 | 中栏是**一行一场的空桌子**（分场条），不是空轨道。 |
| 分支 | 若用户先点时间轴 → 「那是看钟的。写戏请回到分场条。」 |
| 现状 | ❌ 新书默认页签只有时间轴（`workspaceTabs.ts:88-90`）。《渡口》打开也是时间轴（[02-open-default-timeline](./assets/guide-audit/02-open-default-timeline.png)）。空书没有「先建一个人，或写下这场要办成什么」的空态。右栏六块全是「还没有」，像坏了。 |

#### G3 · 没戏也能建人、建地（F17–F21）

| 字段 | 内容 |
|---|---|
| 停留 | 左栏新建行 |
| 气泡 | 「左边是这本书里的人。先建『阿福』，类型选人物，点新建。再建模『渡口』。」 |

#### G4 · 写下这场要办成什么（F10、F42）

| 字段 | 内容 |
|---|---|
| 停留 | 应在「写下一场」左边的输入（理想）；现状无此锚点 |
| 气泡 | 「这场要办成什么？写成一句，例如『阿福发现刀在抽屉』。」 |
| 用户做 | 打字。地点选「渡口」。 |
| 预期 | 「写下一场」从灰变实心。 |
| 分支 | 空着点按钮 → 按钮继续灰，气泡「先写这一句，不然不知道这场要干什么。」（九条第 6 条） |
| 现状 | ❌ 顶栏没有任务框。`intent`/`place-id` 是透明钩子（F16）。人眼输入在右栏场页且无 testid（F42）。未选中场时「写下一场」一直灰（[02](./assets/guide-audit/02-open-default-timeline.png)）。选中已有场后按钮才亮（[05](./assets/guide-audit/05-inspector-scene.png)）——空书永远亮不了，除非误打到钩子。**引导无法把气泡钉在「本场任务」上，因为可见层没有它。** |

#### G5 · 点写下一场（F10）

| 字段 | 内容 |
|---|---|
| 停留 | `write-next` |
| 气泡 | 「点它。会多出一张草稿。还不是历史，改坏了能丢掉。」 |
| 用户做 | 点「写下一场」。 |

### 3.3 术语：文档成立，人眼里不成立

引导气泡必须用人话。现界面若继续用左列，教练词会和屏幕打架。

| 现界面 | 人要听见的 | 现屏问题 |
|---|---|---|
| 本场任务 | 这场要办成什么 | 词可以留，但框要出现在按钮旁 |
| 价值转折 | 这场前后，什么变了 | 卡上可显示「无知→把柄」；空则「还没写变化」不要「未写转折」 |
| 世界账 | 此刻还开着的事（刀在谁那儿） | 空，人觉得功能坏了 |
| 人物账 | 谁知道、谁不知道、谁信错 | 同上 |
| 读者账 | 你看见了、场上有人还不知道 | 空 |
| 写入正史 | 定稿，后面的场会用到 | 词偏文言，但有「历史」感，可留并加一句解释 |
| 写入此框 | 放到这个格子（还没定稿） | 人找不到框 |
| 确认变更 | 时间结构要改，选一种办法 | 建议 id 不像人话 |
| 未归线 | 还没贴到某一条故事线（可以不贴） | 像报错 |
| 未名场 | （不要显示）用「这场要办成什么」当标题 | 满屏未名场 |
| 疏中密 | 卡宽 / 多看几列 | 尚可 |
| 假模型填场 | 模型填这一场 | 「假」像产品坏了 |

**结论：** 不是「差一点点高级感」。是 **主按钮旁边没有主输入、写戏桌子不是默认桌面、一半功能在一个不关门的 ⋯ 里、右栏用账本词展示空数据。** 不符合人工交互。符合的是导出对话框和「打开书能看见场条」。
